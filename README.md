# ⛏ Dig Party — เกมขุดดินสำหรับ TikTok Live

คนดูกด ❤ = ขุด 1 ครั้ง, ส่งของขวัญ = ขุดคูณตามมูลค่า ขุดลงไปเรื่อย ๆ ผ่านชั้นหิน 7 แบบ (วนไม่สิ้นสุด)
คนดูแต่ละคนมีตัวละครของตัวเอง ขุดเจอ **สมบัติ** ที่เก็บสะสมข้ามไลฟ์ และทำให้ขุดแรงขึ้น (สูงสุด ×5)

- หน้าเกมสำหรับ OBS: `http://localhost:3000/game` (แนวตั้ง 1080×1920)
- แผงควบคุม: `http://localhost:3000/control`

## ติดตั้งและรัน

ต้องมี Node.js 22 ขึ้นไป

```bash
npm install
npm run dev          # โหมดพัฒนา
# หรือ
npm run build && npm start   # โหมดใช้งานจริง (ลื่นกว่า แนะนำตอนไลฟ์)
```

## ใส่ในโปรแกรมไลฟ์

**OBS / TikTok Live Studio** → เพิ่ม Source แบบ **Browser**

| ช่อง | ค่า |
|---|---|
| URL | `http://localhost:3000/game` |
| Width × Height | `1080 × 1920` |

เพิ่ม `?debug=1` ท้าย URL เพื่อดู FPS มุมขวาล่าง (ใช้ตอนทดสอบเท่านั้น)

## เชื่อมกับไลฟ์ (เลือก 1 ทาง)

เปิด `/control` แล้วเลือกแหล่งข้อมูล

### ก. TikTok Connector (ค่าเริ่มต้น)

1. ใส่ username ช่องที่ไลฟ์อยู่ (เช่น `@mychannel`) — ต้องกำลังไลฟ์อยู่จริง
2. กด **เชื่อมต่อ**

ใช้ไลบรารี `tiktok-live-connector` ซึ่งต้องผ่าน **Euler Stream** (บริการ sign ภายนอก)
มี rate limit — ถ้าเชื่อมบ่อยแล้วโดนจำกัด ให้สมัคร API key ฟรีที่ eulerstream.com
แล้วใส่ในช่อง API key หรือใส่ใน `.env`:

```
EULER_API_KEY=xxxxxxxx
```

### ข. TikFinity (ทางสำรอง ไม่ผ่านบริการที่สาม)

1. เปิดแอป TikFinity บนเครื่อง และเชื่อมกับไลฟ์ของคุณในแอป
2. เปิดใช้ WebSocket API ในการตั้งค่า TikFinity
3. ใน `/control` เลือก **TikFinity** ใช้ URL `ws://localhost:21213/` แล้วกด **เชื่อมต่อ**

> ใช้ได้ทีละแหล่ง — เปิดพร้อมกันจะนับของขวัญซ้ำ

## ปุ่มในแผงควบคุม

- **เริ่มไลฟ์ใหม่** — ความลึกกลับไปผิวดิน (ของสะสมของคนดูไม่หาย)
  - เชื่อมต่อ Connector กับไลฟ์ใหม่ (room ใหม่) จะรีเซ็ตให้เองอัตโนมัติ
  - เน็ตหลุดแล้วต่อกลับไลฟ์เดิม หรือ refresh หน้า OBS → เล่นต่อจากเดิม
- **ทดสอบ** — ปุ่มจำลอง ❤ / ของขวัญ / เข้าไลฟ์ / `!bag` ใช้ได้โดยไม่ต้องไลฟ์

## คำสั่งในแชท

- `!bag` — โชว์ของสะสมและพลังขุดของคนพิมพ์บนจอ

## ปรับสมดุลเกม

ตัวเลขทั้งหมดอยู่ใน [`src/config/game.ts`](src/config/game.ts)

| ค่า | ความหมาย | ค่าเริ่ม |
|---|---|---|
| `GIFT_MULTIPLIER` | 1 diamond = กี่ครั้งขุด | 10 |
| `BASE_HP` / `HP_GROWTH` | HP ชั้นแรก / อัตราโตต่อชั้น | 100 / 1.15 |
| `DROP_CHANCE_PER_ROLL` | โอกาสได้สมบัติต่อการสุ่ม | 2% |
| `GIFT_ROLL_CAP` | สุ่มสมบัติได้สูงสุดกี่ครั้งต่อของขวัญ | 20 |
| `RARITY_BONUS` | โบนัสพลังขุดต่อชิ้น | +1% / +3% / +8% / +25% |
| `BONUS_CAP` | เพดานพลังขุด | ×5 |
| `ACTIVE_WINDOW_MS` | เงียบนานเท่าไรถึงลงจากบล็อก | 15 วินาที |

## ข้อมูลเก็บที่ไหน

`data/game.db` (SQLite) — คนดู, สมบัติ, และสถานะไลฟ์ล่าสุด
ลบไฟล์นี้ = ล้างของสะสมทั้งหมด

```bash

```

`src/server` (WebSocket hub), `src/game` (Phaser วาดอย่างเดียว), `server.ts` (จุดเริ่ม)
